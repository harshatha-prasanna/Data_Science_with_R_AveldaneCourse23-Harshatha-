# Data_Science_with_R_AveldaneCourse23-Harshatha-
Exploratory data analysis and diabetes prediction modeling using R, applied to a clinical dataset with real-world challenges.

## Diabetes Prediction Analysis in R ## 
This project was completed as part of a Data Science with R course and applies core data science techniques to a real-world clinical dataset containing health indicators for 768 patients, used to predict the likelihood of a diabetes diagnosis.
## Dataset ## 
The dataset includes the following variables: number of pregnancies, glucose level, blood pressure, skin thickness, insulin level, BMI, diabetes pedigree function, age, and a binary outcome indicating diabetes diagnosis. A notable characteristic of this dataset is the presence of missing values across several clinical variables, reflecting the kind of data quality challenges common in real-world medical records.

## Tools and Libraries ## 
This project was built in R using the tidyverse for data manipulation and visualization, rmarkdown for reproducible reporting, and leaflet for interactive mapping where applicable.

## Skills Demonstrated ## 
Data cleaning and handling of missing values, exploratory data analysis, statistical modeling, and data visualization.

## Context ## 
This was an early project in my data science journey and represents my first hands-on experience working with messy, real-world clinical data in R.
